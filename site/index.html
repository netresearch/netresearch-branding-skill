Live WCAG contrast verifier

The brand docs hard-code contrast ratios — but contrast is symmetric, so a pair cannot have two different values. These rows are computed in your browser from the hex values, both ways: WCAG 2.x relative luminance, and APCA (APCA-W3 0.1.9). Where the document’s stated number disagrees with the math, the mismatch is flagged.

The two columns answer different questions. WCAG is the compliance gate and is not negotiable. APCA is a perceptual readability measure: its Lc is signed — positive means dark text on a light background, negative the reverse — and the size it permits depends on the font weight, so there is no single passing number. A pair can clear WCAG and still read poorly at 14px, and an APCA pass never waives a WCAG failure. The APCA reading column names the smallest regular-weight (400) text the Lc allows, from APCA’s own font table.

Canonical CSS variables

→ Finding F1

SKILL.md prescribes --nr-primary, --nr-accent, --nr-text, --nr-border, --nr-bg and NB-16 enforces them. The references and templates use the same names, with the role suffixes the contrast rules need: -fill for a surface under white text, -text for type at body size, -deep for its hover, -strong for the boundary of a control.

Sizes

→ Finding F5

SKILL.md recommends 40–56px in headers; logo.md recommends ≥120px as a visual anchor. Both say “recommended” — which wins, when?

✓ Do
  • Keep the turquoise frame dominant, the grey “n” clearly visible.
  • Use on white or very light neutral backgrounds.
  • Link clickable instances to netresearch.de.
✗ Don’t
  • Recolor, add gradients, strokes, glows or drop-shadows.
  • Rotate, skew, distort or crop the mark.
  • Replace with a generic placeholder icon.
